# Paulo Restaurant Website

A modern, responsive restaurant website designed and developed for Paulo Restaurant.

## Project Overview

The Paulo Restaurant website is a custom restaurant website inspired by modern restaurant web experiences, with a focus on visual presentation, usability, responsive design, and reservations.

The website is being developed using the restaurant's branding, content, photography, and other assets provided by the client.

## Features

- Responsive design for desktop, tablet, and mobile
- Restaurant-focused homepage
- About section
- Restaurant menu
- Image gallery
- Automatic image carousel/gallery
- Reservation functionality
- Events and catering section
- Contact section
- Google Maps integration
- Social media links
- Mobile-friendly navigation
- SEO-friendly structure
- Performance optimization
- SSL/HTTPS deployment

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
